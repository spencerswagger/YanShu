## 块矩阵

- 实测（96 MiB → 96 块）：DOM 格数 **96**、列数 **32**，均 ≤ 上限；
- 规则单测（`web/tests/matrix.test.js`，6 例）：1024 块 → **1024 格**（1 块/格）；4096 块 → **1024 格**（4 块/格）；移动 1024 块 → **100 格**（11 块/格）；
- 帧预算：`planFrames(1024)` 切成 **16 帧 × 64 格**，单帧 ≤ **64**。
